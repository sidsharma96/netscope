# M7: bounded classic PCAP and recorded layers

Implemented October 13, 2026 under the request to complete remaining planned milestones. Explicit `netscope --pcap FILE` (or `--pcap -- FILE`) selects offline packet inspection; HAR and saved-request paths retain their contracts. Redirected output describes records and stream evidence. No packet action starts network traffic or constructs a replay draft.

Classic PCAP 2.4, either byte order, microsecond or nanosecond timestamp fractions. Require a complete 24-byte global header, nonzero snaplen no larger than 256 KiB, supported plain 16-bit link metadata, complete 16-byte record headers and stored byte ranges, captured length <= snaplen/original length, and valid fraction range. Reserved historical timezone/accuracy fields are ignored. Reject PCAPNG and additional FCS metadata explicitly. Budgets: 32 MiB file, 20000 records, 256 KiB stored record. Reads stop at file budget plus one byte. Container failure aborts the import atomically with a byte offset and fixed reason, never raw captured values.

Layer subset: Ethernet (1), at most two 802.1Q/802.1ad tags; BSD loopback (0) with address family 2 for IPv4 and 10, 24, 28 or 30 for IPv6, in either byte order; Linux cooked SLL (113) and SLL2 (276); raw IP (101), IPv4 (228), IPv6 (229). Unknown link/payload types remain stored with an unsupported explanation. Parse IPv4 base/options lengths, total length and addresses (a total length of 0 with a longer frame is labelled a segmentation offload capture, and the record's original length stands in for it), but exclude fragments from transport interpretation. Parse IPv6 base header with direct TCP/UDP next header; extension headers, empty/jumbo payloads remain outside transport interpretation. Check TCP variable header length, flags, sequence/ACK/window, and retained/declared payload bounds. The declared payload is the IP-declared end (IPv4 total length, or IPv6 header plus payload length) minus the IP and TCP headers, set in [`declared_payload`](https://github.com/sidsharma96/netscope/blob/main/crates/netscope-import/src/pcap.rs#L354); the retained range is clipped to the captured bytes. Ethernet padding after the IP-declared end is therefore never TCP payload. Also check UDP length/endpoints/capture completeness. Do not validate checksums, negotiated window scaling, receiver acceptance, TLS, QUIC, IP fragment reassembly, Wi-Fi or other link formats. Unsupported/malformed inner layers retain prior valid metadata and packet bytes instead of rejecting an otherwise framed recording.

The model owns each record's bytes and stores checked payload ranges. Record order and timestamps remain exporter observations; fractions converted to nanoseconds do not claim nanosecond accuracy. UI: packet list, Enter inspector, p packets/s streams, Esc returns, arrows/jk/pages/Home/End, help, q/Ctrl+C, small-window recovery and terminal cleanup. Hex preview is capped at 256 bytes, values escaped, shortened displays labelled. IDs are original record positions. Unsupported fields never become zero-valued synthetic layers.

Evidence: [fixtures/provenance](https://github.com/sidsharma96/netscope/blob/main/tests/fixtures/pcap/README.md), import tests [`classic_orders_layers_and_source_ranges_are_checked`](https://github.com/sidsharma96/netscope/blob/main/crates/netscope-import/tests/pcap.rs#L10), fixed UI buffers [`packet_views_and_navigation_preserve_selected_records`](https://github.com/sidsharma96/netscope/blob/main/crates/netscope-tui/tests/packets.rs#L24), PTY check [`check_packet_terminal.py`](https://github.com/sidsharma96/netscope/blob/main/scripts/check_packet_terminal.py#L1), and [beginner byte/layer lesson](../chapters/29-reading-packet-bytes.md). This subset is not whole-PCAP/libpcap or protocol conformance, live capture, decryption, or proof of complete delivery.
